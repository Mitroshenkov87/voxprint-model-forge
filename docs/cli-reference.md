# CLI reference

Generated from `forge` (`voxprint_forge.cli.build_parser`).
Do not edit this file by hand. Run `python -m voxprint_forge.cli_reference`.

## `forge`

```text
usage: forge [-h] [--version] [--json] [--root ROOT] [--plan PLAN] [--forge-out FORGE_OUT] {plan-summary,verify-logins,preflight,status,accounts,sources,run-all,fetch,abliterate,quantize,eval,card,publish-prep,upload,fit,canvas,diffusion-int4,compare,kl,lora,index} ...

positional arguments:
  {plan-summary,verify-logins,preflight,status,accounts,sources,run-all,fetch,abliterate,quantize,eval,card,publish-prep,upload,fit,canvas,diffusion-int4,compare,kl,lora,index}
    plan-summary        Print the plan's time estimate.
    verify-logins       Check Hugging Face and Kaggle logins.
    preflight           Run the seconds-long checks and print the report.
    status              Read status.json and report stalled or failed work.
    accounts            Store Hugging Face, Kaggle, and Drive credentials in the OS
                        keyring.
    sources             Record that a consumer has finished with a shared download.
    run-all             Run every enabled model through upload.
    fetch               Download pinned files for one model.
    abliterate          Run the refusal-direction ablation for one model.
    quantize            Build the importance matrix and GGUF quants.
    eval                Record perplexity, refusal rate, and prose samples.
    card                Render the model card.
    publish-prep        Write the registry draft.
    upload              Upload files and verify sha256 and size. Hub repos are public.
                        Kaggle stays private.
    fit                 Measure quants and record the VRAM/RAM split for each tier.
    canvas              Prepare canvas image tiers.
    diffusion-int4      Wan 2.2 GGUF and FP8.
    compare             Score original and compressed arms for one synth4 job.
    kl                  Perplexity and KL of GGUF quants against an F16 base.
    lora                Train a LoRA from your photos: prepare, train, extend, export.
    index               Build or push the model index, or backfill voxprint-model.json.

options:
  -h, --help            show this help message and exit
  --version             show program's version number and exit
  --json                Print one JSON object on stdout.
  --root ROOT           Repo root. Default: search from the working directory.
  --plan PLAN           Plan TOML. Default: plans/plan.toml.
  --forge-out FORGE_OUT
                        Output root. Default: the plan output directory.
```
